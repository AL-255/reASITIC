Development previewThe workbench retains ASITIC’s conductor, filament, capacitance, eddy and network models. Cross-section integrals use scale normalization and adaptive software precision to control cancellation; the integration error-power term uses a guarded square-root formulation. The same C++ mathematics is checked in native and WASM builds against independent high-precision references. Original instruction rounding is audited separately.
